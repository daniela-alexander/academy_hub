# 🎓 Academy Hub

Plataforma web que conecta **academias y alumnos**, permitiendo publicar, descubrir y gestionar cursos.

## 🚀 Funcionalidades

* 🏫 Gestión de academias, profesores y cursos.
* 📅 Convocatorias con fechas, plazas, horarios y precios.
* 👨‍🎓 Registro, perfiles e inscripciones.
* 📝 Admisión, reservas y lista de espera.
* 💳 Pagos, descuentos y becas.
* 🔔 Recordatorios automáticos.
* 📊 Evaluaciones y seguimiento del progreso.
* 🧠 **“¿Este curso encaja conmigo?”** y Pasaporte de Talento.

## 🛠️ Tecnologías

**Python · Django · SQLite · HTML · CSS · JavaScript**

Futuro: **PostgreSQL · Redis · Celery · Docker · Django REST Framework · IA**

## ⚙️ Instalación

```bash
git clone <URL_DEL_REPOSITORIO>
cd academy-hub

python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/Mac

pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Abrir en: `http://127.0.0.1:8000/`

## 🎯 MVP

Registro y login · Perfiles · Academias · Profesores · Cursos · Convocatorias · Inscripciones · Búsqueda y filtros.
